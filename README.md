# Arbor · Algorithm Learning Lab

Arbor is a standalone, frontend-only tree visualization workspace inspired by the feature-based React architecture and visual styling of the Chess frontend.

## Run locally

```sh
cd frontend
npm install
npm run dev
```

Build the production frontend with `npm run build`.

## Current features

- Free-form binary and n-ary tree editing with React Flow.
- BST, AVL, min/max heap, M-way search tree, and B-tree construction and operations.
- Array construction, JSON import/export, and browser-local project persistence.
- Binary tree reconstruction from inorder paired with preorder or postorder traversals.
- Playback controls, per-run operation counters, theoretical complexity summaries, and English/French switching.

All algorithms run in the browser. No account or backend is required.
