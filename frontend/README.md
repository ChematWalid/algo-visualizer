# Arbor · Algorithm Learning Lab

Standalone React + TypeScript frontend for visualizing search trees, heaps, and their algorithms. It follows the feature-oriented structure and dark sage-green styling used by the Chess frontend reference.

## Start

```sh
npm install
npm run dev
```

`npm run build` type-checks the app and builds the production bundle.

The app stores the current project in browser local storage. Use Import / Export to move projects as JSON. No backend is required.
